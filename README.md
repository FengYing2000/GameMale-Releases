## 📲 安装教学

### Android

1. 从上面的 GitHub 或百度网盘下载 `.apk`
2. 打开下载好的文件安装（第一次可能要允许「安装未知来源的应用」）
3. 之后有新版，App 会提示，点一下就能下载更新

### iOS（侧载）

iOS 版没有上架 App Store，需要自行侧载。**推荐 SideStore + LiveContainer**，教学很多，不会的话上网搜索「SideStore 安装教程」「LiveContainer 教程」。

<details>
<summary><b>点击展开：SideStore + LiveContainer 大致流程</b></summary>

1. 照 [SideStore 官网](https://sidestore.io) 的教程，用电脑把 SideStore 装到 iPhone（只有第一次要用电脑）
2. iPhone 打开「设置 → 隐私与安全性 → 开发者模式」，重启后确认开启
3. 到 [LiveContainer](https://github.com/LiveContainer/LiveContainer) 下载 IPA，在 SideStore 的「My Apps」点左上角 **+** 安装
4. 下载 GameMale 的 `.ipa`，用 LiveContainer 打开导入，之后从 LiveContainer 里启动
5. 免费 Apple ID 的签名 **7 天**到期，记得在 SideStore 里点「Refresh」续签 LiveContainer

**好处**：GameMale 装在 LiveContainer 里，不占免费账号「最多 3 个侧载 App」的名额。

</details>

<details>
<summary><b>点击展开：其他方式</b></summary>

- **只用 SideStore**：在 SideStore 的「Sources」加入下面的来源，之后在 SideStore 里安装、自动更新
  ```
  https://852111.xyz/api/app/source.json
  ```
- **AltStore**：电脑装 AltServer → 装 AltStore → 用 AltStore 安装 IPA（续签时电脑要开着、同一个 Wi-Fi）
- Sideloadly 等其他侧载工具也可以

</details>

### 网页版（免安装）

用手机打开 [**852111.xyz**](https://852111.xyz)，照画面指示添加到主屏幕，之后**从主屏幕的图标打开**，就能像 App 一样使用。

| 手机 | 怎么添加 |
| :-- | :-- |
| iPhone | 用 **Safari** 打开 → 底部「分享」→「添加到主屏幕」 |
| Android | 用 **Chrome** 打开 → 右上角菜单 →「安装应用」或「添加到主屏幕」 |

> [!NOTE]
> 网页版只能从手机主屏幕打开；在浏览器分页或电脑上打开，只会看到添加到主屏幕的说明。
> 在微信、Telegram 等 App 里点开的链接没办法添加，请先选「在浏览器中打开」。

## 💬 问题回报

> [!IMPORTANT]
> 问题回报请用 **App 内回报** 或 **论坛私信**，不在 GitHub 处理。

- **「回报」小按钮（最方便）**：画面边缘的小按钮，在出问题的那一页按一下，会自动附上当下画面的截图、版本和设备（不想给人看的截图送出前可以拿掉）。小按钮可以在「设置 → 版本与更新」关掉
- **我的 → 回报问题**：一样能回报；右上角「我的回报」看得到处理状态和开发者的回复
- **论坛私信**：需要附录屏、或账号相关的问题
- 想要的新功能、觉得不好用的地方也欢迎提

## 🔒 隐私

- 账号只存在你自己的手机里，**不会**上传密码或任何登录凭证
- App 直接连论坛；网页版经由转发服务器连到论坛，服务器不保存账号资料
- 登录后会记下论坛昵称、UID、设备型号、系统和 App 版本、使用时间，用来统计和排查问题；**没登录不记录**
- 会花金币、积分的操作（买勋章、兑换……）都会先确认

<summary><b>网页版和 App 有什么不一样？</b></summary>

功能基本一样。网页版不用安装、不用续签；App 直接连论坛，速度更快。iPhone 不想侧载的话用网页版就好。
