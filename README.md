# GameMale

GameMale 論壇的手機客戶端。這裡只放安裝檔。

> 目前是測試階段，第一次開啟要輸入**測試碼**。

## 下載

到 [Releases](https://github.com/FengYing2000/GameMale-Releases/releases/latest) 下載最新版：

- **Android**：下載 `.apk`，直接安裝。
- **iOS**：下載 `.ipa`，用 LiveContainer、Sideloadly 等側載工具安裝。

## iOS 用 SideStore 自動更新

在 SideStore 的「來源（Sources）」按 **+**，加入：

```
https://852111.xyz/api/app/source.json
```

之後有新版，SideStore 會自己提醒，一鍵更新。

## 不想裝 App

用手機開 <https://852111.xyz>，照畫面指示**加入主畫面**，之後從主畫面的圖示打開，就能像 App 一樣使用，不用側載。

- **iPhone**：Safari → 分享 → 加入主畫面
- **Android**：Chrome → 右上角選單 → 安裝應用程式（或加到主畫面）

網頁版只能從手機主畫面打開，在瀏覽器分頁或電腦上開只會看到加入主畫面的說明。

## 更新內容

每一版的更新內容寫在各個 Release 裡，App 的「設定 → 版本與更新 → 更新日誌」也看得到。
